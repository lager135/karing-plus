Karing+ 0.2.0_b
================

VPN-клиент для Windows на базе Karing (автор nebula / KaringX, лицензия GNU GPL v3).

Первый запуск
-------------
1. Откройте Karing+ и добавьте подписку: Настройки -> Профили -> Добавить профиль.
2. Нажмите большую кнопку на главном экране. При первом подключении Windows
   спросит права администратора (UAC): так ставится служба ядра KaringPlusService.

Возможности Karing+
-------------------
- Режим TUN: весь трафик системы идёт через VPN (переключатель на главном экране).
- Режимы обхода: VPN, Zapret или VPN+Zapret, у Zapret можно выбрать стратегию.
- Российские сайты в обход VPN: Настройки -> Подключение -> «Российские сайты в обход VPN»
  (.ru, .su, .рф, Яндекс, VK и др. открываются напрямую).
- Раздача Wi-Fi-хотспота с VPN и/или Zapret, с QR-кодом (значок Wi-Fi на верхней панели).
- На главном экране: время подключения, внешний IP и число соединений.

Обновления
----------
Karing+ сам проверяет новые версии на https://github.com/lager135/karing-plus/releases
Если закрыть окно с предложением обновиться, оно не появится 24 часа.
Новую версию ставьте поверх старой: настройки и профили сохраняются.

Где что лежит
-------------
Программа:          папка, выбранная при установке (по умолчанию C:\Program Files\Karing+)
Настройки, профили: %APPDATA%\KaringPlus
Лог установщика:    %TEMP%\Setup Log *.txt

Удаление: «Параметры -> Приложения -> Karing+ -> Удалить». Настройки в %APPDATA%\KaringPlus остаются.
