# Karing+

VPN-клиент для Windows, Android и Linux на базе [Karing](https://github.com/KaringX/karing) (автор nebula / KaringX, лицензия GNU GPL v3).

## Что добавлено в Karing+

- Windows: служба ядра с режимом TUN, встроенный zapret (режимы «VPN / Zapret / VPN+Zapret» со стратегиями), раздача Wi-Fi-хотспота через VPN с QR-кодом.
- Android: российские приложения (банки, Госуслуги, маркетплейсы, операторы) работают в обход VPN.
- Windows и Linux: российские сайты (.ru, .su, .рф, Яндекс, VK и др.) открываются в обход VPN.
- На главном экране: время подключения, внешний IP, число соединений.

## Версии

Формат `X.Y.Z_b` (бета): исправление ошибок — `Z+1`, небольшая доработка — `Y+1`, крупное обновление — `X+1`.
Сборки публикуются в разделе [Releases](https://github.com/lager135/karing-plus/releases).
